\section{Statement}
Given a positive integer $n$ and a set of nonnegative real numbers $x_1,x_2,\dots,x_n$, we can define their arithmetic mean as $\frac{x_1+x_2+\dots+x_n}{n}$ and their geometric mean as $\sqrt[n]{x_1x_2\dots x_n}$. The AM-GM inequality states that the arithmetic mean (AM) is always no less than the geometric mean (GM).
\section{Proof}
Our goal is to prove that for nonnegative reals $x_1,x_2,\dots,x_n$, $\frac{x_1+x_2+\dots+x_n}{n}\geq\sqrt[n]{x_1x_2\dots x_n}$.\\
Firstly, this result trivial for $n=1$, because $LHS=\frac{x_1}{1}\geq x_1=RHS$.\\

Also, the result is true for $n=2$ because for nonnegative reals $x_1,x_2,(\sqrt x_1-\sqrt x_2)^2\geq0\Rightarrow x_1+x_2-2\sqrt{x_1 x_2}\geq0\Rightarrow x_1+x_2\geq2\sqrt{x_1 x_2}\Rightarrow LHS=\frac{x_1+x_2}{2}\geq \sqrt{x_1 x_2}=RHS.$\\

Next, assume this result is true for $n=k$; that is, for any nonnegative reals $x_1,x_2,\dots,x_k$, $\frac{x_1+x_2+\dots+x_k}{k}\geq\sqrt[k]{x_1x_2\dots x_k}$. It also follows that for nonnegative reals $x_{k+1},x_{k+2},\dots,x_{2k}$, $\frac{x_{k+1}+x_{k+2}+\dots+x_{2k}}{k}\geq\sqrt[k]{x_{k+1}x_{k+2}\dots x_{2k}}$. \\
Therefore, adding the two, $\frac{x_1+x_2+\dots+x_{2k}}{k}\geq \sqrt[k]{x_1x_2\dots x_k}+\sqrt[k]{x_{k+1}x_{k+2}x_{2k}}$, so $\frac{x_1+x_2+\dots+x_{2k}}{2k}\geq \frac{\sqrt[k]{x_1x_2\dots x_k}+\sqrt[k]{x_{k+1}x_{k+2}x_{2k}}}{2}$.
The result is already proven for $n=2$, therefore, so it must be true that $\frac{A+B}{2}\geq\sqrt{AB}$ for $A=\sqrt[k]{x_1x_2\dots x_k},B=\sqrt[k]{x_{k+1}x_{k+2}x_{2k}}$. That is, $\frac{x_1+x_2+\dots+x_{2k}}{2k}\geq \frac{\sqrt[k]{x_1x_2\dots x_k}+\sqrt[n]{x_{k+1}x_{k+2}x_{2k}}}{2}\geq \sqrt{(\sqrt[k]{x_1x_2\dots x_k})(\sqrt[k]{x_{k+1}x_{k+2}x_{2k}})}=\sqrt[2k]{x_1x_2\dots x_{2k}}.$ Therefore, for this case, the result is true for $n=2k$.\\

Next, assume this result is true for $n=l$ for some positive integer $l\geq2$; that is, for any nonnegative reals $x_1,x_2,\dots,x_l$, $\frac{x_1+x_2+\dots+x_l}{l}\geq\sqrt[l]{x_1x_2\dots x_l}$. \\
We may set $x_l$ as $\frac{x_1+x_2+\dots+x_{l-1}}{l-1}$. Then, $\frac{x_1+x_2+\dots+x_l}{l}=\frac{x_1+x_2+\dots+x_{l-1}}{l}+\frac{\frac{x_1+x_2+\dots+x_{l-1}}{(l-1)}}{l}=\frac{((l-1)+(1))(x_1+x_2+\dots+x_{l-1})}{l(l-1)}=\frac{x_1+x_2+\dots+x_{l-1}}{l-1}=x_l.$ Therefore, $x_l\geq\sqrt[l]{x_1x_2\dots x_l}\Rightarrow x_l^l\geq x_1x_2\dots x_l\Rightarrow x_l^{l-1}\geq x_1 x_2\dots x_{l-1}\Rightarrow x_l\geq\sqrt[l-1]{x_1x_2\dots x_{l-1}}\Rightarrow \frac{x_1+x_2+\dots+x_{l-1}}{l-1}\geq\sqrt[l-1]{x_1x_2\dots x_{l-1}}$. Therefore, for this case, the result is true for $n=l-1$.\\

In conclusion, the result is true for $n=1$ and $n=2$. If the result is true for $n=k$, then it is true for both $n=2k$ and $n=k-1$ (for $k\geq2$). Therefore, the result is true for all positive integers $n$ by mathematical Cauchy induction.
